# Radhe Dhoundiyal

I work on mathematics, scientific computing, and engineering projects. I like following a question from a notebook or an experiment into something I can test: a program, a proof attempt, a dataset, or a working interface.

## Selected projects

### Mathematics you can explore

**[PRISM Arcade](https://github.com/Radhe-Dhoundiyal/prism-arcade)** · [Try the arcade](https://prism-arcade-live.vercel.app/)

Eight interactive environments built around PRISM India mathematics problems. The games sit alongside earlier notebook investigations and later corrections, including places where my original arguments did not hold up.

### Astronomy and scientific computing

**[TESS Transit Detectability](https://github.com/Radhe-Dhoundiyal/tess-transit-detectability-v1)**

A study of when a blind transit search recovers signals in archived TESS light curves. The repository contains selected results, recovery and injection code, a small runnable example, and a record of an injection-model correction.

### Engineering software

**[GravityMapper](https://github.com/Radhe-Dhoundiyal/GravityMapper)** · [Open the dashboard](https://gravitymapper.onrender.com/)

The telemetry, run-management, CSV-processing, and mapping software for my broader GADV rover project. Its sensor-derived gravity values are exploratory proxies, not calibrated gravitational measurements.

### Number theory

**[Benford-weighted digit sums](https://github.com/Radhe-Dhoundiyal/benford-weighted-digit-sums)** · [Prime-power digit sums](https://github.com/Radhe-Dhoundiyal/prime-power-digit-sums-paper-1) · [Cross-base fluctuations](https://github.com/Radhe-Dhoundiyal/prime-power-digit-sums-paper-2)

Mathematical manuscripts and computational reproducibility packages investigating digit sums of prime powers and leading-digit behavior of exponential sequences.

## Following the work

I keep the methods, source material, validation checks, and known limitations with the individual projects. Where an earlier argument or implementation turned out to be wrong, I try to show the correction instead of presenting only the final result.
